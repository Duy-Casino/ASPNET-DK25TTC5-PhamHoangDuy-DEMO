# Ảnh đại diện giảng viên demo

Ảnh minh họa của **giảng viên ảo, không phải người thật**, chỉ dùng cho dữ liệu mẫu (`Seed:DemoPassword`).

- Nguồn: phong cách "Notionists" của Zoish (https://heyzoish.gumroad.com/l/notionists), xuất qua DiceBear 9.x.
- Giấy phép: **CC0 1.0** (https://creativecommons.org/publicdomain/zero/1.0/). Thông tin giấy phép cũng nằm trong thẻ `<metadata>` của từng file SVG.
- Backend chỉ chấp nhận ảnh đại diện là URL https, ảnh tải lên (`/uploads/...`) hoặc ảnh trong thư mục này (`/avatars/demo/...`).

Khi triển khai thật, giảng viên tự tải ảnh chân dung của mình trong trang **Khu vực giảng dạy › Hồ sơ giảng viên**.
